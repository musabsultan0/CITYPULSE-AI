# Roadmap
1. Run the demo end-to-end.
2. Choose one city and a few zones.
3. Integrate documented public data sources and synthetic IoT feed with clear provenance.
4. Add PostGIS geometry and spatial queries.
5. Train traffic, flood and AQI models on appropriate real labelled data.
6. Evaluate models using chronological/spatial holdouts and baseline comparisons.
7. Improve RAG with metadata, citations, hybrid search, reranking and evaluation.
8. Add LLM provider adapter with structured output and strict schema validation.
9. Add LangGraph parallel fan-out, persistent checkpoints and human approval identity/audit.
10. Add monitoring, security, deployment and load testing.
